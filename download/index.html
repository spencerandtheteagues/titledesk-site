What is new in v0.2.4

  • Copies update themselves. From this version TitleDesk checks for a newer release in the background and applies it only when you quit the app yourself; nothing changes while you are working, and the next launch is the new version. Copies older than 0.2.4 have no updater, so this one install is by hand.
  • Remote support, on your terms. Settings → Remote support gives you a one-time code to read to your TitleDesk support contact. Nothing is shared until you approve the connection a second time inside the app, and only the TitleDesk window itself is ever shown or controlled — never your desktop, files or other programs. A banner stays visible while support is active; its Stop button ends the session at once, and a session expires on its own after 30 minutes.

What arrived in v0.2.3

  • An ended licence asks for a code. When a trial or subscription ends, TitleDesk now asks for a new activation code instead of stopping at an "ended" screen with no way forward.
  • Manage or cancel from the site. title-desk.com/manage opens your billing portal from the email on your receipt, long after the purchase; you no longer need the receipt page.
  • Linux, signed. The x86_64 AppImage ships alongside macOS and Windows, with a detached GPG signature and the public key to check it against.
  • Project cards say what they are. A project card names its workflow rather than an internal identifier.

What arrived in v0.2.2

  • Paste the assignment and go. Multi-abstract assignments and every named party are read as data; one paste runs every abstract under one budget, and the run fails itself if any abstract or person never reached a county search.
  • Chains that stay on the tract. A multi-abstract chain is scoped to its own abstract, a name collision cannot drop a deed from the package, and a spouse's marital descriptor is no longer read as a surname.
  • Ownership derived, not restated. Mineral interest in the delivered workbook is derived per tract from the examined evidence; unresolved tracts are labelled unresolved rather than certified.
  • Delivery you can verify. Every uploaded file is pinned to the hash the verification gate approved; a package with no verification record is undeliverable.
  • Metered research with a ceiling. Paid county lookups run inside a dollar budget you set per assignment, and every download books its cost.
  • Hardening. Electron fuses close the asar-edit and debugger-attach paths; the research browser refuses any host that resolves to a private address; documents handed to a connected model are framed as data, never instructions.
  • Your own AI, pinned. Bring a Codex or Claude subscription and pin the model TitleDesk uses from Settings, or run with no AI at all.
  • Read every page. Multi-page TIFF instruments are read page by page; ruled-table OCR and long legal descriptions survive intake.

First launch

  1. macOS: open the image and drag TitleDesk Agent to Applications. The image is signed under an Apple Developer ID and notarized, so it opens normally the first time. Windows: run the signed installer. Linux: mark the AppImage executable (chmod +x) and run it.
  2. Open TitleDesk and paste the activation code from your receipt page or email. Each seat is one computer; the same code activates every seat you bought.
  3. Once activated it keeps working offline for extended periods.
