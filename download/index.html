What is in v0.2.0

  • Paste the assignment and go. Multi-abstract assignments and every named party are read as data; one paste runs every abstract under one budget, and the run fails itself if any abstract or person never reached a county search.
  • Chains that stay on the tract. A multi-abstract chain is scoped to its own abstract, a name collision cannot drop a deed from the package, and a spouse's marital descriptor is no longer read as a surname.
  • Ownership derived, not restated. Mineral interest in the delivered workbook is derived per tract from the examined evidence; unresolved tracts are labelled unresolved rather than certified.
  • Delivery you can verify. Every uploaded file is pinned to the hash the verification gate approved; a package with no verification record is undeliverable.
  • Metered research with a ceiling. Paid county lookups run inside a dollar budget you set per assignment, and every download books its cost.
  • Hardening. Electron fuses close the asar-edit and debugger-attach paths; the research browser refuses any host that resolves to a private address; documents handed to a connected model are framed as data, never instructions.
  • Your own AI, pinned. Bring a Codex or Claude subscription and pin the model TitleDesk uses from Settings, or run with no AI at all.
  • Read every page. Multi-page TIFF instruments are read page by page; ruled-table OCR and long legal descriptions survive intake.

First launch on macOS

  1. Open the image and drag TitleDesk Agent to Applications.
  2. The first time, right-click the app and choose Open. Gatekeeper warns because the evaluation image is signed ad hoc rather than under an Apple Developer ID; a notarized image follows.
  3. Enter the activation code from your licence or evaluation email. Each seat is one computer, and it keeps working offline once activated.
