Verified installation

Get the right TitleDesk build.

Installers for Windows, macOS and Linux are published with a SHA-256 checksum for every file, so you can confirm what you downloaded is exactly what we released.

Download

Download TitleDesk Agent

  1. Pick the file for your computer: Windows (-win-x64-Setup.exe), macOS (-mac-…dmg, Apple Silicon), or Linux (-linux-x86_64.AppImage).
  2. Check it against the SHA256SUMS file on the same page — Get-FileHash on Windows, shasum -a 256 on macOS and Linux.
  3. Install it, then open your one-time activation link on that computer. Keep that link private.

Windows and macOS code signing is still being completed, so those installers are not yet signed: Windows will show a SmartScreen notice and macOS will ask you to confirm the first open. Verifying the checksum above is what proves the file is ours. Windows guide · macOS guide · Linux guide
