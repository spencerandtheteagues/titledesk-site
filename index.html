How it works

From the record.
To the whole picture.

You define the assignment and bring the instruments. The run does the reading, the chain and the arithmetic, and hands you a workbook to review.

  1. 1

    Type in the assignment

    Paste the scope as you received it, choose the Texas county, and enter each tract with its abstracts and gross acres. Add the names to research and upload the instruments you hold as PDF, TIFF, PNG or JPEG. A helper reads what you type and explains how to fix a mistake.

  2. 2

    Pass the check, then pay

    Before any charge, the check compares the abstracts in your text with the tracts you typed and adds the tract acres against your total. If something is off you see exactly what and where, and nothing is charged. When it passes, you read the summary back, confirm it, and pay for the run.

  3. 3

    Two examiners work the chain

    The first examiner reads the instruments, builds the chain of title and works the ownership in exact fractions. A second, separate examiner checks that work and writes the workbook. A running timer and a single status line show what each model is doing. You can close the page; the run carries on without you.

  4. 4

    The workbook arrives

    When the workbook is written it is emailed to you automatically as an attachment, and a copy stays in your account. Review it, check it against the sources, and sign it yourself. If a run cannot be finished, one run is credited to your account.

Follow the interest

One estate.
Every interest.

A reservation changes the ownership. A probate carries it forward. A mineral deed divides it again. Follow those interests through the recorded instruments, all the way to net mineral acres.

Before you pay

Get the land right.
Before the run.

See how the assignment check identifies scope errors before a run. The example below is wrong in two places: an abstract named in the text is missing from the tracts, and the acres do not add up. The check reads the scope of the assignment. It does not read ownership.

Illustrative assignment check

Two details that change the scope.

The sample text names Abstracts 101 and 102 under Tract 1, plus Abstract 240 under Tract 2. The tracts contain 160 and 52.54 acres.

The first entry lists only Abstract 101 under Tract 1 and gives a total of 212.45 acres.

This is a fixed example, using invented information. Live assignment entry will open with the browser workspace.

Two things need attention

  • Missing abstract

    Abstract 102 appears in the assignment but is missing from the tract entry.

  • Acreage total

    160 + 52.54 = 212.54 acres. The entered total of 212.45 does not match.

See the corrected sample

Tract 1: 160 acres, Abstracts 101 and 102.
Tract 2: 52.54 acres, Abstract 240.
Total: 212.54 gross acres.

The scope now agrees with itself. This does not establish ownership or prove that the record is complete.

During the run

Watch it work, or walk away.

The moment a run starts, a timer starts with it. One line on the screen says what the model at work is doing right now, and when the next step begins that line is replaced. There is no log to scroll and no progress bar that guesses.

  • The timer shows the elapsed time for the whole run.
  • The status line names the model and the step: Model 1, the first examiner, then Model 2, the second.
  • The workbook is emailed the moment it is written. You do not need to keep the page open.

Questions

Straight answers.

Is this a title opinion?

No. It is a draft examination for review by a qualified professional. It reflects only the documents in the run. You check it, and you decide what to rely on.

When am I charged?

Before the run starts. The check comes first and costs nothing. Once the assignment passes and you confirm it, your card is charged and the run begins. Plans are billed in advance, by the month or the year.

What if a run cannot be finished?

One run is credited to your account automatically. The credit covers one run of the same kind, up to the pages you paid for. It does not expire, and your next run uses it before any card is charged. It is a run credit, not a refund. If the run came out of a plan, it goes back into that plan’s allowance.

What happens if the check stops my assignment?

You see exactly what needs attention and where. Nothing is charged, because the check comes before payment. Fix it and check again as often as you like.

How long does a run take?

It depends on the number of instruments and the length of the chain. The timer shows the elapsed time, and you do not need to stay on the page: the workbook is emailed when it is finished. No turnaround time is promised.

Which files can I upload?

PDF, TIFF, PNG and JPEG. A run reads up to 400 pages; larger runs add $40 for each further 200 pages, shown before you pay.

Where does it work?

Texas, one county per run.

What if an instrument is missing?

The workbook names each instrument the chain cites that was not among your documents, by volume and page, so you know what to pull. On an upload run, nothing is bought for you.

How do I sign in?

By email. Enter your address and we send you a one-time link. There is no password to remember.

Is this the same as the TitleDesk desktop app?

No. TitleDesk Desktop Agent is a separate product that you install and license for each computer. The planned browser service needs nothing installed. About the desktop app.
