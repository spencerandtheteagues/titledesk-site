The job

Title work is still a factory. Most of the hours are mechanical, and those are the hours TitleDesk takes.

County packets, OCR, runsheets, exact fractions, curative lists, and a client folder tree that must match the house format. TitleDesk does that work on the laptop. The landman accepts what is true, refuses what is thin, and keeps the opinion.

PHASE 01

Taking the assignment

3 capabilities

Paste Your Assignment

Paste the assignment letter your client sent. TitleDesk reads it as data, never as instructions, extracts the requirements, tells you plainly what it can and cannot do, and writes a plan in two columns — its work and yours — that run at the same time.

Two-column work plan

Every task is owned by either TitleDesk or the landman. Anything moved to the landman's column is marked manual and is never touched automatically.

Rounds until it's done

When a round finishes, TitleDesk works out what is still outstanding from the project's own records — not by asking a model whether it is finished — and plans the next round. Only the landman closes an assignment.

PHASE 02

Reading the documents

4 capabilities

On-machine OCR

Scanned county records are read locally on the laptop with Tesseract. No OCR API, no internet connection and no per-page cloud charge. Measure throughput on your actual packet and hardware.

Multi-page instruments

Recorders return whole instruments as one multi-page image. TitleDesk processes each page and surfaces extraction failures for review, including exhibits and lease schedules on later pages.

Document classification

Works out what each document is — lease, opinion, unit designation, plat, probate, and twenty-three instrument types in all — and which submission folder it belongs in, using your company's own naming conventions where you have them. Filename beats body text, so a ratification does not steal the instrument it recites.

Nothing disappears quietly

A page OCR cannot read is marked "needs your eyes" rather than being recorded as blank. Thin OCR stays empty rather than inventing a plausible lessor.

PHASE 03

Building the work product

7 capabilities

Runsheet

Recorded instruments in chronological order with grantor, grantee, volume and page, instrument number and interest — each row linked to the page it was read from. Chain gaps are flagged, not hidden. Word and Excel export in the company's columns.

Row provenance

Entries record how they were read: entered by a person, read off the page deterministically, or proposed by a model and accepted. Review source links and provenance before delivery.

Curative and issues list

Unleased interests, unreleased prior leases, probate and heirship gaps, assignment-chain defects — each with the document and page it came from, and a proposed next step. The list a landman actually works, not a chatbot summary.

Ownership by tract

Mineral and leasehold ownership tracked per tract, with balance checking so an interest that does not total to one is flagged rather than rounded away. Net mineral acres, leasehold, held-by-production and conflicts included.

Exact fraction arithmetic

Interests are stored and computed as exact BigInt rationals, never floating point. 1/3 + 1/3 + 1/3 is exactly 1. A 1/3 of 160.33 acres stays exact all the way to the report, and an over-conveyance is reported as an exact excess such as "over by 1/4". Money is integer cents.

Wells, leases and production

Texas RRC production data imported and matched to wells and leases, with gap detection across production months. Canonical 42-CCC-NNNNN API identity — partial county codes are not wells. RRC workbooks import by sheet without confusing the API number, lease number or district.

Heirship tree

Estates, heirs and determinations mapped, with each determination held for review before it affects ownership.

PHASE 04

Delivering it

4 capabilities

Your workbook, filled in

Reports are written into the company's own Excel template — matching your column names to TitleDesk's by meaning, never overwriting a row a person has corrected, and never touching a column it was not asked to map. Ten report types in Word, Excel, PDF or CSV.

Submission package

Builds the folder tree you actually turn in, every document filed in the folder your client expects, named to your convention. Originals are copied, never moved. Empty folders stay visible so missing work is obvious — or you suppress them.

Gaps stated out loud

If a report would be delivered with nothing in it, or a document is too thin to put on the runsheet, the build says so rather than shipping something that merely looks finished.

Save straight to Drive

A user can direct a finished package to a separately connected personal Google Drive. Delivery to a personal Drive is hash-pinned: every uploaded file is verified against the package the gate approved.

PHASE 05

Control and safety

8 capabilities

Local by default

Local OCR and exact arithmetic stay on the machine. Automated title examination sends selected page images to the AI provider you chose after consent; Drive, county-records and other connectors receive only what their task requires. A company Drive is treated as read-only by application rules and database guardrails.

The model stays reviewable

AI readings and ownership conclusions remain proposed and source-linked. A model cannot certify title or overrule the landman; unresolved evidence and qualifications stay visible.

Bring your own AI

Runs against whatever model access the landman already has — Claude, Anthropic, OpenAI, Moonshot, a local Ollama model, or a custom endpoint — rather than a company-wide token bill. Local OCR has no per-page AI charge; automated document examination may use the connected provider's quota or API credits. Consent-gated; untrusted assignment text never gets tools.

Local work without AI

Local OCR, project records, exact-fraction arithmetic, billing and report assembly remain available without AI. The current automated title-assignment and page-examination workflow requires a connected AI that can read page images.

Append-only audit log

Every consequential action is recorded and cannot be edited or deleted, including by the software itself. If a determination was accepted, rejected or changed, that is on the record with who did it.

Research stays inside the fence

A dedicated research browser with its own profile touches only domains you have approved, with spending safeguards built in for paid sources such as CourthouseDirect and TexasFile. Take-over for passwords. The official Texas RRC is always allowed.

Encrypted at rest

AES-256-GCM database. Key held in the macOS Keychain, Windows DPAPI or Linux libsecret — never in a file next to the data.

Workspaces and licensing

One TitleDesk installation switches between companies without a custom build, with an isolated encrypted database per workspace — one company's workspace cannot read another's. Device-based seats, offline lease, Stripe Customer Portal, activation from licenses@theharnesslab.com.

The product inside the product

Customization Lab — TitleDesk becomes your shop.

No two land departments file, search, or deliver the same way. Forking the app per client does not scale. A free-form template language would let a model write code. Customization Lab is the third path: you describe the workflow in English. TitleDesk proposes a validated company profile. Nothing is written until a person approves the plain-language change.

“Ownership report as Word, not Excel. Call Owner ‘Mineral Owner’. Package folder {{project.name}} - Landman Submitted {{date.today}}. Search back to sovereignty. Always pull ratifications. Upload finished work to my personal Drive, never the company Drive.”

Research process

Preferred domains — Courthouse Direct, TexasFile, the RRC, and the hosts you allow. How far back title is run: sovereignty, or a house year count. Adjoining tracts. Gap thresholds. Document types you always pull. Defects worth raising. Require a human on every instrument, or only the thin ones.

Sources & connections

Both company and personal Drive connections use Google's narrow drive.file Picker scope, limited to items the user selects or TitleDesk creates. TitleDesk treats company Drive as read-only in application rules and database guardrails. Personal Drive can receive finished packages when you say so. Connector hosts must be approved before use.

Formatting of finished work

Each report type — runsheet, ownership, curative, document index and more — chooses Excel, Word, PDF or CSV. Columns, labels, order, freeze header, draft watermark, company name, logo, accent colour, footer. Placeholders like {{project.county}} are a closed list; unknown tags are refused at save, not printed on a client PDF.

Questions land departments actually ask

Before you commit.

How can a title assignment take twenty minutes when it takes a landman days?

The days go to mechanical work: pulling the county index, reading instruments, transcribing runsheet rows, working conveyances through the ledger, fraction arithmetic, balance checks, writing up defects and assembling the folder tree. TitleDesk does that part in about twenty minutes on real assignments. The landman's judgment, reviewing the chain against the cited pages and certifying, is the part that stays, and is budgeted at two to three hours. The arithmetic is on the ROI page.

Has TitleDesk been used on real assignments?

Yes. It has been run end to end on real Texas title assignments that a working landman had already completed by hand, and the workbook it produced was compared cell by cell against the landman's approved report. Those assignments are replayed in the automated test suite before every release.

Do my title documents go to the cloud?

Local OCR, exact-fraction arithmetic and report assembly run on your computer. The current automated title-examination workflow sends selected page images to the AI provider you chose after consent; Drive, county-records and other connectors receive only what their task requires. See the table above for the full breakdown.

Does it need an internet connection?

Local OCR and existing project files can work offline. Automated assignment research needs internet access for the county-records provider, the selected AI and Drive delivery; licensing also checks in periodically.

Do I have to use AI?

Local OCR, project records, exact-fraction arithmetic, billing and report assembly work without AI. The current automated title-assignment and page-examination workflow requires a connected AI that can read page images; you select the provider, and TitleDesk tests it before searching or spending.

Why does the ownership math matter so much?

Because decimals lie. 1/3 as a decimal is 0.333…, and three of them do not add to 1. Run that through a chain of title and the error compounds into real money. TitleDesk uses exact fractions, so 1/3 + 1/3 + 1/3 is exactly 1, and an over-conveyance is reported as an exact excess such as "over by 1/4".

Can I trust what the AI extracted?

You are not asked to. Every extracted date, party and fraction stays proposed until you accept it, and every material number carries a link back to the page it came from. The AI proposes; the landman decides.

I work for several companies. Will their data get mixed?

No. Each company configuration is an isolated workspace with its own encrypted database. One company's workspace cannot read another's, and you switch between them explicitly. A company workspace can also be removed from your computer entirely, along with its data.

Can a company set TitleDesk up once and hand it to its landmen?

Yes — that is exactly what the 15-day build-out and Customization Lab are for. A company configures policy, security posture and research procedure, then distributes that configuration. The landman does not reassemble it.

Can I install it on more than one computer?

Seats are counted per device: one seat is one licensed computer. Some earlier contracts retain their original device allowance. Tell us if you need to move an activation to a different machine.

What happens when my licence expires?

TitleDesk switches to restricted operation. Existing work remains readable and exportable, and project files stay on disk; creating or changing work requires an active licence.

My activation link expired, or never arrived.

Paid-purchase activation links are single-use and last ten minutes. Evaluation invitations remain redeemable until the deadline stated in the invitation. Email comes from licenses@theharnesslab.com — check spam first, then email sales@theharnesslab.com from the address you purchased or requested with.

Is the source code available? We have procurement requirements.

TitleDesk is commercial software; the public repository carries releases and documentation only. Companies with requirements around source escrow or independent security review should contact spencer@theharnesslab.com directly — those arrangements are made, not refused.

Why does macOS warn when I first open TitleDesk?

From v0.2.2 it should not. The macOS images are signed with an Apple Developer ID and notarized by Apple, and the notarization ticket is stapled to the disk image, so the app opens normally the first time and does so even if the Mac is offline. The Windows installer is Authenticode-signed. If you still see a warning you are on an older build — take v0.2.8. Every download has a published SHA-256 checksum on the download page.
